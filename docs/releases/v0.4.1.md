# v0.4.1

安全边界与长期运行稳定性维护版。重点修复 MCP 对外上传地址和命令生成、任务过滤与
取消状态一致性、前端跨会话异步写回，以及临时文件与停机生命周期问题。Web API 的
路径、请求/响应结构和错误码保持兼容，只新增可选查询参数与配置项。

部署在反向代理或 HTTPS 后面的 MCP 用户升级前必须阅读文末的
`JUST_PRINT_PUBLIC_BASE_URL` 配置要求。

## 🔐 MCP 与 HTTP 安全

- **MCP 上传地址不再信任代理请求头**：新增显式
  `JUST_PRINT_PUBLIC_BASE_URL`。配置后上传地址只从该 origin 生成；未配置时只接受
  字符集受限、可解析为 authority 的 `Host`，不再使用可被客户端伪造的
  `X-Forwarded-Proto`。生成 URL 会经过 shell 引用，`curl` 增加
  `--fail-with-body`，避免请求头内容进入命令结构。
- **MCP 设备名与缓存有界**：设备头只接受字母、数字、点、下划线和连字符；
  设备服务按最近使用时间回收空闲条目，容量满时不再永久拒绝新设备，而是清理空闲
  服务或返回可重试的 503。
- **公共 HTTP 中间件覆盖所有入口**：`x-request-id`、请求超时、HTTP 指标、安全头和
  `Cache-Control: no-store` 现在同时覆盖 `/api`、`/mcp`、`/uploads/{ticket}` 与
  健康检查。
- **修复 MCP 打印内部路由缺少 `RequestId`**：`print_document` 经内部
  `/api/print` 调用时会因缺少扩展返回空 500；内部路由现在独立注入请求上下文，
  并有完整回归测试。

## 🛠 任务与运行时稳定性

- **任务过滤在截断前执行**：`GET /api/jobs` 的 `active` 过滤不再先截断再过滤；
  新增可选 `printer_id` 参数，并在 limit 前按设备筛选。MCP `list_jobs` 直接使用
  服务端设备过滤，不再依赖 4 倍过取，历史任务很多时也不会漏掉本设备任务。
- **取消状态可保留**：取消任务后不再删除应用层登记元数据，并记录
  `terminal_status`。即使 CUPS 清理任务历史，刷新页面仍能看到取消状态、文件名和
  可重打的文件关联。
- **CUPS 缓存有界**：任务状态缓存增加 1024 条上限和过期清理；打印机选项目录改为
  最多 4 路并发读取，刷新多打印机时不再串行等待。
- **预览引用覆盖完整流**：`FileGuard` 持有到响应体结束或客户端断开，避免 TTL
  清理/人工删除与预览流竞争。
- **转换产物可靠回收**：`LibreOffice` profile、Markdown 中间 HTML 和未完成 PDF
  使用 RAII 守卫，覆盖普通错误、超时与 future 取消。
- **临时文件总量上限**：已转换文件总字节数受 `JUST_PRINT_MAX_TEMP_BYTES` 限制，
  超限返回可重试的 503，不会无限占满 tmpfs。
- **票据上传槽位顺序修正**：先获取上传槽再兑换一次性票据，排队或超时不会白白
  消耗票据。
- **探针有独立预算**：`/readyz` 默认 3 秒超时，短于容器健康检查的 5 秒；CUPS
  不可达时在预算内返回 503。
- **优雅停机**：打印提交由 `TaskTracker` 跟踪，停止接收请求后最多等待
  `JUST_PRINT_SHUTDOWN_TIMEOUT_SECS`（默认 30 秒）完成幂等收尾；Compose/Quadlet
  示例同步扩大停止宽限期，避免运行时提前 SIGKILL。
- **配置组合 fail-closed**：启动时校验幂等 TTL、转换超时、临时 TTL 与总容量等
  相互依赖的限额，拒绝会破坏幂等或清理语义的组合。

## 🎨 前端

- **异步结果绑定会话代次**：登录/登出递增会话 epoch，上传、预览、打印机列表、
  格式列表、任务查询和打印提交在写回状态前检查 epoch；退出登录会中止等待中的
  打印请求，迟到响应不会污染新会话。
- **任务终态补查不再静默失败**：非 404 错误进入指数退避重试；已从 active 列表
  消失的任务使用最多 4 路并发补查，避免串行多个 HTTP 超时；取消成功后本地立即
  显示取消状态。
- **通知有界**：最多保留 20 条，防止长期错误/轮询把内存和版面无限撑大。

## 升级说明

接口路径、请求/响应结构和既有错误码保持兼容；`GET /api/jobs` 仅新增可选
`printer_id`，取消任务现在保留元数据到既有 TTL。没有数据库迁移，直接替换镜像即可。

**反向代理 / HTTPS 部署必须配置**：

```bash
JUST_PRINT_PUBLIC_BASE_URL=https://print.example.com
```

旧版本会自动信任 `X-Forwarded-Proto`；v0.4.1 不再信任该头。未配置公共基地址时，
MCP 上传地址只会从经过校验的 `Host` 推导 `http://`，反代场景可能生成错误地址。
同时建议把运行时停止宽限期设为 45 秒，与 `JUST_PRINT_SHUTDOWN_TIMEOUT_SECS=30`
的停机预算匹配。
