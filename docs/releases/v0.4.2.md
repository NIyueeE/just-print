# v0.4.2

依赖安全修补版：`pulldown-cmark` 0.13.5 → 0.13.6，清除 RUSTSEC-2026-0433。该公告只
影响开启 `ENABLE_WIKILINKS` 的用法，本项目只启用 TABLES / STRIKETHROUGH /
TASKLISTS，运行时不受影响；但锁文件里的受影响版本会让 CI 的依赖审计作业失败，因此照常
升级。无功能改动，无损升级。

## 🔐 依赖与安全

- **pulldown-cmark 0.13.5 → 0.13.6**：修复 RUSTSEC-2026-0433——开启
  `ENABLE_WIKILINKS` 时，嵌套图片 wikilink（`![[![[![[…]]]]]]`）的解析开销随嵌套深度
  平方增长，可用于耗尽内存（denial-of-service，CVSS 3.1 7.5）。修复随
  [#1186](https://github.com/pulldown-cmark/pulldown-cmark/pull/1186) 进入 0.13.6。
  `src/conversion.rs` 的 Markdown 渲染不启用该选项，行为无变化。
- `cargo audit`：0 漏洞、0 警告；`bun audit --audit-level=high`：0 漏洞。
- 版本号同步到 0.4.2（`Cargo.toml` 与 `frontend/package.json`）。

## 🧪 测试与验证

- `just check` 全绿：`cargo fmt --check`、`cargo clippy --all-targets
  --all-features -D warnings`、`cargo test --all-features`（90 个）、前端
  `tsc -b` / ESLint / Prettier / Vitest（63 个）/ `vite build`、入口脚本断言。
- Markdown 打印样式由既有单测覆盖（标题、代码块、表格、任务列表、原始 HTML 转义、
  守护段），升级后全部通过。
