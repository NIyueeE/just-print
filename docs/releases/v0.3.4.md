# v0.3.4

收尾修复：驱动回落路径更稳、示例配置去掉冗余项、令牌写法避坑，并纠正 v0.3.1–v0.3.3
发布说明里的镜像地址笔误。

## 🐛 修复

- **`JUST_PRINT_USB_PPD` 写错不再丢打印机**：队列创建现在依次尝试
  「指定 PPD + 选项」→「指定 PPD、不带选项」→「通用 PPD」，全部失败才告警；
  此前 PPD 路径写错会让 `lpadmin` 整体失败，打印机直接不出现在 `/api/printers`。
- **镜像地址笔误**：v0.3.1–v0.3.3 的发布说明写成了 `ghcr.io/niyuee/...`（少一个 e），
  正确是 `ghcr.io/niyueee/...`。仓库文档与已发布的 GitHub Release 说明均已更正。
- **Quadlet 示例的 `Memory=2g` 改为 `PodmanArgs=--memory=2g`**：Podman 5.4 的
  Quadlet 不支持 `Memory=`，会直接导致 generate 失败。

## 📚 文档

- 明确**只有 `JUST_PRINT_TOKEN` 是必填项**，其余变量都有默认值；`examples/` 下的
  Compose / Quadlet / env 示例只保留必填项，可选项以注释列出，不再重复镜像默认值
  （`JUST_PRINT_ADDR`、`JUST_PRINT_WEB_DIR`、`JUST_PRINT_CUPS_URI`）与脚本默认值
  （`JUST_PRINT_AUTO_USB=1` 等）。
- 新增长期踩坑说明：令牌不要写进 `Environment=`——它会出现在
  `systemctl show` / `podman inspect`，且 systemd 对 `Environment=` 会做 **% 说明符
  展开**（`%%` 会变成 `%`，含 `%` 的令牌被静默改写）；`EnvironmentFile`（600 权限）
  按字面读取，不受影响。令牌用 `openssl rand -hex 32` 生成。
- 部署文档补充「最小可用配置」示例。

## 🧪 测试

- `just shell` 覆盖入口脚本语法与 18 项纯逻辑断言；`just check` 全绿：后端 32 个
  测试、前端 44 个测试。

## ✅ 验证

- 容器冒烟：镜像构建 + CUPS-PDF 端到端。
- Quadlet 示例用 Podman 5.4 自带生成器（`quadlet -dryrun`）验证可通过。
