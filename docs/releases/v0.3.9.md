# v0.3.9

前端修复版：把移动端窄屏适配问题逐条实测并修掉（用 mock API + 无头浏览器在
320 / 360 / 390 / 414 / 768 / 667×375 横屏下逐屏截图核对），同时修掉一批客户端
状态与竞态缺陷。**后端、CUPS 集成、容器入口脚本均无改动**，镜像内容只有前端
产物变化，属于无损升级。

## 📱 移动端窄屏（截图与实测确认）

- **错误通知会永久盖住确认对话框的按钮（阻断级）**：`--z-toast` 高于 `--z-modal`，
  而底部通知堆栈与对话框操作区在窄屏上完全重叠。实测在确认按钮中心做命中测试，
  命中的是 `notice__message` ——「确认打印 / 取消」点不到，且错误通知不会自动
  消失。现在通知层级降到模态框之下（对话框自身已内联展示同一条错误），并在
  对话框打开期间锁定页面滚动、出错时自动滚到底部的错误与按钮处。
- **顶栏「退出登录」在 320px 被压成两行**：≤420px 时三个按钮被 `flex: 1` 均分，
  文案按钮只剩 1/3 宽度。改为图标按钮保持方形、文案按钮按内容排布，并让按钮
  文案默认不折行（长文案按钮如「恢复推荐设置」单独允许折行，避免撑破卡片）。
- **触控目标过小**：通知关闭（26px）、上传错误关闭（24px）、对话框关闭（30px）、
  令牌显示/隐藏（30px）在触屏上很难点中。用 `::after` 扩大命中区域、不改版面，
  并在 ≤640px 显式加大尺寸。
- **横向安全区未计入**：`viewport-fit=cover` 下横屏刘海会压住内容，顶栏/内容区
  现在按左右安全区留白；通知层改用左右定位 + `margin-inline: auto`，适配不对称
  安全区。
- **对话框用 `100vh` 定高**：移动端地址栏收放时 `100vh` 大于可视高度，底部按钮
  会落到地址栏之后。改为相对（已含安全区的）遮罩区域取 `max-height: 100%`，并
  加 `overscroll-behavior: contain`。
- **触屏上仍显示「按 Tab / Enter」键盘说明**：改用 `@media (pointer: coarse)` 收进
  可访问性树（保留 `aria-describedby` 有效），窄屏版面明显变紧凑。
- **iOS/移动端滚动背景**：`background-attachment: fixed` 在移动端会随滚动重绘甚至
  被忽略，换成独立的 `position: fixed` 氛围光晕图层；可点击元素加
  `touch-action: manipulation` 去掉双击缩放的点击延迟。
- 其他：任务计数不再被拆成「已取消 / 0」两行；预览 iframe 高度改 `clamp()`，横屏
  下不再占满整屏；打印机型号/位置等超长串允许断行，不再撑破卡片；空白 `<select>`
  的取值兜底（见下）。

## 🐛 其他前端修复

- **一次打印机刷新失败会让整个打印面板消失**：错误分支原本整块替换掉选择框、
  全部选项和「提交打印」，明明还能用却像服务挂了。现在保留已拿到的列表，只在
  顶部提示错误。
- **数字选项清空后仍按旧值提交**：界面已是空值、状态里还留着旧值（例如份数显示
  空白却印 5 份）。空值现在写回状态，并按「打印机默认」处理。
- **打印机目录变化后仍提交旧键**：读取选项目录失败或打印机重置后，残留的旧键会
  被服务端判为 `invalid_controls`（400）整单拒绝。提交前按当前目录与空值过滤。
- **枚举/分辨率默认值可能匹配不到候选项**：服务端若给出非候选项形式的默认值，
  `<select>` 会渲染成空白。默认值现在会归一到候选项（数字形式也识别），保证控件
  始终有值。
- **移除文件未中断预览请求**：晚到的预览响应会写入无人使用的 blob URL（不再回收），
  并让服务端的 DELETE 因引用计数返回 409。现在移除/重新上传前先中断预览。
- **提交被中止后对话框永久 busy**：按钮全禁用、Esc 失效，只能靠退出登录脱身。
  新增 `print/abort` 在取消时复位。
- **无效文件会丢弃已上传的文件与预览**：拖入不支持的格式时不再清空当前选择，
  只提示错误；上传成功后主按钮变为「已上传并转换」并禁用，避免重复上传产生
  服务端孤儿文件。
- **主题切换一次后再也回不到「跟随系统」**：改为 跟随系统 → 浅色 → 深色 → 跟随系统
  三态循环（图标与文案表示当前偏好，可访问名说明点击后的结果）。
- 其他：`GET /api/formats` 失败后新增「重试」入口；任务列表首屏加载失败不再被
  静默吞掉（此前会让人以为「没有任务」）；手动刷新在卸载时中断、被取代的请求不再
  提前收起 spinner；打印失败时补上 `Retry-After` 等待提示；修正「每 5 秒自动重试」
  与指数退避不符的文案。

## ✅ 验证

- `just check` 全绿：后端 **33** 个测试、前端 **54** 个测试（新增 10 个回归用例：
  选项默认值归一、空值=打印机默认、`print/abort` 复位、对话框滚动锁、主题循环、
  提交负载过滤）、入口脚本 16 项断言。
- 窄屏走查：mock API + Vite + 无头 Chromium，在 320–1280 共 22 个宽度下扫描
  文档与元素级横向溢出（含对话框、上传后、打印失败等状态），结果为 0 溢出；
  并对「对话框按钮可点击」「主题循环」「刷新失败后列表仍在」「触屏隐藏键盘提示」
  等修复做了行为验证。
