# v0.3.10

界面精炼 + 后端修复版：前端在保持 Gruvbox 风格与宽窄屏适配的前提下大幅降噪
（长句改为短语/图标，专业名词收进 Hover Tooltip），后端修掉三个经回归测试实证的
缺陷——幂等键容量淘汰、打印机移除后任务列表、Markdown 守护段。测试从 33 个增至
50 个，新增「上传 → 打印 → 查询 → 取消 → 删除」全链路集成测试（进程内假 IPP
服务端驱动真实路由）。镜像内容同时包含前后端产物变化，属于无损升级。

## 🎨 前端降噪与 Tooltip（mock API + 无头浏览器实测）

- **专业名词全部收进 Hover Tooltip**：新增 `Tooltip` 组件（纯 CSS 驱动，hover 与
  键盘聚焦均可展开，贴边/顶部元素有方向变体）。界面只保留中文标签（纸张大小 /
  单双面 / 分辨率 / 每张版面…），悬停才显示 IPP 属性名与含义，如
  「IPP sides · 单双面；长边装订适合纵向文档，短边适合横向」；确认对话框的摘要行
  同样挂了解释。屏幕阅读器通过 `aria-describedby` 读到同一段文字，视觉与可访问性
  语义一致。
- **按钮图标化**：退出登录、主题切换、刷新、重置、取消上传、移除文件、清除已
  结束、取消任务、重新打印都改为图标按钮，完整语义放在 `aria-label` 与 Tooltip；
  图标按钮保持方形命中区，≤1080px 同步放大到 44px。
- **长句改短语**：CUPS 排查建议、选项目录失败、重启丢元数据等长提示压缩为一行
  结论，完整说明移到 Tooltip；确认对话框描述精简为「打印是物理操作，提交后无法
  撤回。」；格式/大小信息从整段说明改为卡片头部元信息行；键盘操作说明收进可访问性
  树；32 位任务 id 只显示 `#前8位`（悬停看全量）；任务统计改为 chip（悬停各有
  释义）。
- **去掉冗余**：份数（份）这类标签自带的单位后缀移除（单位由 Tooltip 与确认摘要
  承载）；卡片头与 FlowSteps 重复的数字角标移除；登录页删掉冗长的令牌存储说明
  （该内容属于部署文档）。

## 🐛 后端修复（均有「先红后绿」的回归测试）

- **幂等键容量淘汰可能吃掉「进行中」的键（重复出纸风险）**：容量写满时按时间淘汰
  最旧条目，可能选中一个请求已受理、响应未返回的 `InProgress` 条目。该键被淘汰后，
  同键重试会拿到 `Fresh` 并再次提交，幂等保护失效。现在只淘汰 `Completed` 条目，
  全部条目都在进行中时停止淘汰（容量被并发量短暂突破，由 TTL 兜底）。
- **打印机从 CUPS 移除后 `GET /api/jobs` 整表 404**：任务登记表里残留已删除打印机
  的任务时，`Get-Jobs` 返回 `not-found` 会让整个列表请求失败。现在按「该打印机没
  有任务」处理：其余打印机的任务照常返回，已删除打印机的任务按 `已清理` 展示。
- **Markdown 以列表/HTML 块开头时首个标题会被 LibreOffice 吞掉（内容丢失）**：
  LibreOffice 的 HTML 导入会吃掉正文第一个段落/标题，守护段旧逻辑只在「第一个解析
  到的块」是段落/标题时才插入；文档以列表、表格或 HTML 块开头时 `first_block` 被
  提前消耗，后面的标题拿不到守护段。现在按「第一个实际输出的段落/标题」插入，
  列表内容与标题都保留。
