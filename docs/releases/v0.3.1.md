# v0.3.1

USB 打印机的可用性修复：内置 HPLIP PCL 驱动、改进 PPD 型号匹配，并新增
`JUST_PRINT_USB_OPTIONS` 用于声明双面器等硬件相关选项。

## ✨ 新功能

- **内置 HPLIP PCL 驱动**（`printer-driver-hpcups`，约 2 MB）：USB 自动建队列时
  优先命中厂商 PPD。以 HP LaserJet 4000 为例，之前只能落到
  `Generic PCL Laser Printer`，现在可命中 `HP LaserJet 4000 Series`。
- **`JUST_PRINT_USB_OPTIONS`**：逗号或空格分隔的 `key=value`，创建队列时追加
  `lpadmin -o`；已存在的同名队列也会被更新。例如通用 PCL PPD 用
  `Option1=True`，HPLIP PPD 用 `OptionDuplex=True` 声明双面器已安装。
- **型号匹配改进**：把前导 `lj` 还原为 `laserjet`、去掉能力后缀得到系列名、
  在字母/数字边界容忍 `-` / `_` / 空格，并优先选择厂商 PPD（避免总是落到
  `sample.drv` 的通用驱动）。

## 🐛 修复

- **USB 打印机无法选择双面**：通用 PCL PPD 会把 `Duplex` 绑定在可安装选项
  `Option1/Duplexer`（默认 `False`）上；CUPS 生成 IPP `sides-supported` 时会做
  可安装冲突检查，冲突成立时只上报 `one-sided`，所以界面只有「单面」，而
  `lpoptions -l` 却仍列出 `DuplexNoTumble` / `DuplexTumble`。内置 HPLIP 驱动
  （其 PPD 不把 Duplex 绑定到可安装选项）并支持声明选项后，界面可正常出现双面。

## 升级提示

- 若你的 USB 打印机此前落到通用 PCL PPD，升级后新容器会自动重新建队列并优先
  匹配厂商 PPD；已持久化 `/etc/cups` 的部署可手动删除队列后重启，或用
  `JUST_PRINT_USB_OPTIONS` 声明硬件选项。
- 双面等能力仍以 CUPS 上报的 IPP 属性为准；若界面没有双面，先在容器内
  `grep -iE 'Installable|UIConstraints' /etc/cups/ppd/<队列>.ppd` 确认选项名，再用
  `JUST_PRINT_USB_OPTIONS` 声明。
