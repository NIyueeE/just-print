# v0.3.2

v0.3.1 的一处健壮性修复：`JUST_PRINT_USB_OPTIONS` 里写错选项名/取值时，不会再有
「打印机整个消失」的后果。

## 🐛 修复

- **选项被 `lpadmin` 拒绝时退回不带选项重试**：`lpadmin -o key=value` 会整体失败，
  此前会导致队列创建失败、打印机从 `/api/printers` 消失。现在会打 warning 并改用
  不带任何选项的方式重新创建队列（例如把 `OptionDuplex=True` 误写成 HPLIP 之外的
  名字时，队列仍会正常出现）。

## 📚 文档

- 部署文档补充 `JUST_PRINT_USB_OPTIONS` 的合法取值来源：它是 `lpadmin -o` 的透传，
  取值由队列 PPD 决定；用 `lpoptions -p <队列> -l` 查询，可安装选项固定为
  `False`/`True`（通用 PCL PPD 是 `Option1`，HPLIP PPD 是 `OptionDuplex`）。

## ✅ 验证

- `just check` 全绿：后端 32 个测试、前端 44 个测试、入口脚本 8 项断言。
- 容器冒烟：镜像构建 + CUPS-PDF 端到端。
